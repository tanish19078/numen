# Neobank Design Tokens Reference

| Role | Token | Hex / Value | Usage |
| :--- | :--- | :--- | :--- |
| Canvas | `bg-canvas` | `#F7FAF8` | Global app background |
| Surface | `bg-surface` | `#FFFFFF` | Primary cards, rail, tables |
| Subtle Surface | `bg-subtle` | `#F1F6F3` | Nested wells, hover rows, code blocks |
| Hairline Border | `border-line` | `#E2EBE5` | 1px borders across all cards/dividers |
| Pine Ink | `text-pine` | `#0B1F16` | Headlines, KPI numbers, primary text |
| Sage Ink | `text-sage` | `#526B5D` | Subtitles, metadata, field labels |
| Emerald Primary | `text-emerald` | `#059669` | Verified checks, active pills, CTA buttons |
| Mint Wash | `bg-mintWash` | `#ECFDF5` | Soft success tags & highlight tint |
| Card Dark Pine | `bg-cardPine` | `#0D261C` | Brushed 60-second virtual card surface |
| Crimson Threat | `text-threat` | `#DC2626` / `#FEF2F2` | Blocked injections & spoofed domains |
| Amber Review | `text-review` | `#D97706` / `#FFFBEB` | Fine-print traps & HITL Passkey holds |
| Display / Body Font | `font-sans` | `"Plus Jakarta Sans"` | Headings (600-800) & body (400-500) |
| Mono Font | `font-mono` | `"JetBrains Mono"` | PANs, hashes, latency, JSON, badges |
